C++: The Lower you get & The Deep it gets

What is C++? C++ is a super-fast, object-oriented compiled programming language built directly on top of C. Unlike HTML (which draws web pages), C++ talks straight to your computer's CPU and RAM—powering game engines (Unreal), browsers (Chrome), operating systems, and high-speed trading. It is an independent language that provides low-level control while offering high-level abstractions without needing any other language.

  • Setup in 60 Seconds: Install a compiler (GCC / g++ on Linux/Windows MinGW, or Clang on Mac) and open an editor like VS Code or Code::Blocks.
  • How it runs: You write human code in main.cpp → the compiler translates it into raw 1s and 0s (an executable) → your CPU runs it at lightning speed!

Basics

A C++ program is written in source files, usually with a .cpp extension or .cc extension maybe even .c++, your choice. It is a compiled programming language, meaning the code is compiled directly into an executable that your computer can actually run like a .exe file on Windows.

1.1 Program Structure

Every executable C++ program starts execution from main().

#include <iostream>

int main() {
    std::cout << "Hello World!";
    return 0;
}
  • #include: Includes a library or header file.
  • int main(): The program's entry point.
  • { }: Define a block of code.
  • ;: Ends a statement.
  • return 0;: Indicates successful program termination.

1.2 Comments

Comments are ignored by the compiler. They help explain code.

// Single-line comment

/*
   Multi-line
   comment
*/

Variables & Data Types

Variables store data that a program can access and modify. Every variable has a data type that determines what kind of value it can hold.

2.1 Variable Declaration

Declare a variable by specifying its type and name. You can also assign an initial value.

int age;           // Declaration
age = 16;          // Assignment

int score = 100;   // Initialization

2.2 Data Types

C++ provides several fundamental data types:

Type Stores Example
int Whole numbers int x = 10;
float Decimal numbers float x = 3.14f;
double Higher-precision decimals double x = 3.14159;
char Single characters char grade = 'A';
bool True or false bool active = true;
void No value / return type void display();
std::string Text std::string name = "Alex";

2.3 Constants

Use const to declare a variable whose value cannot be changed after initialization.

const double PI = 3.14159;

2.4 Type Conversion

C++ can convert values between data types automatically or through explicit casting.

// Implicit conversion
int x = 10;
double y = x;

// Explicit conversion
double price = 9.99;
int rounded = static_cast<int>(price);
Remember: Choose a data type based on the kind of value you need to store. Use const when a value should not change.

Input & Output

C++ provides stream objects to read input and display output. They are available through the <iostream> header.

3.1 Output — cout

std::cout prints data to the standard output, usually your terminal. Use << to send values into the stream.

std::cout << "Hello World!";
std::cout << 100 << '\n';

3.2 Input — cin

std::cin reads input, usually from your keyboard. Use >> to store the entered value in a variable.

int age;

std::cout << "Enter your age: ";
std::cin >> age;

std::cout << "Age: " << age;

3.3 Reading Full Lines

std::cin >> stops reading at whitespace. Use std::getline() to read an entire line, including spaces.

#include <string>

std::string name;

std::cout << "Enter your name: ";
std::getline(std::cin, name);

std::cout << "Hello, " << name;
Important: If you use std::getline() immediately after std::cin >>, consume the leftover newline first (for example, with std::ws).

3.4 Other Output Streams

  • std::cerr: Displays error messages.
  • std::clog: Displays diagnostic or logging messages.
std::cerr << "An error occurred!\n";
std::clog << "Application started.\n";

3.5 Escape Sequences

Escape sequences represent special characters inside strings and character literals.

Sequence Meaning
\n New line
\t Horizontal tab
\\ Backslash
\" Double quotation mark
\' Single quotation mark 
std::cout << "Hello\nWorld!";
std::cout << "Name:\tAlex";

2. Conditional Statements

Conditional statements control which block of code executes based on a condition.

2.1 if, else if & else

Use if to check a condition, else if to check another, and else as the fallback.

int score = 85;

if (score >= 90) {
    std::cout << "Grade A";
} else if (score >= 75) {
    std::cout << "Grade B";
} else {
    std::cout << "Keep practicing!";
}

2.2 switch

Use switch when comparing one expression against multiple exact values. break prevents execution from falling through into the next case.

int day = 2;

switch (day) {
    case 1: std::cout << "Monday"; break;
    case 2: std::cout << "Tuesday"; break;
    default: std::cout << "Other";
}

2.3 Ternary Operator

A shorter way to choose between two values based on a condition.

int age = 18;
std::string result = (age >= 18) ? "Adult" : "Minor";
Remember: Use if-else for general conditions, switch for exact-value comparisons, and the ternary operator for simple two-way choices.

3. Loops

Loops repeat a block of code while a condition is satisfied.

3.1 for Loop

Best when the number of iterations is known. It contains initialization, condition, and update.

for (int i = 0; i < 5; i++) {
    std::cout << i << " ";
}

3.2 while Loop

Checks the condition before each iteration. It may execute zero times.

int n = 3;

while (n > 0) {
    std::cout << n << " ";
    n--;
}

3.3 do-while Loop

Checks the condition after execution, so it always runs at least once.

int x = 3;

do {
    std::cout << x << " ";
    x--;
} while (x > 0);

3.4 Loop Control

  • break: Immediately exits the loop.
  • continue: Skips the current iteration and moves to the next.
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;
    if (i == 5) break;

    std::cout << i << " ";
}
Remember: for is useful for counted repetitions, while for condition-based repetition, and do-while when execution must happen at least once.

2. Functions (Reusable Code Machines)

Functions slice a giant program into small, named mini-machines. Feed inputs in → get an answer back.

2.1 Functions

int add(int a, int b) {   // ReturnType Name(Parameters)
    return a + b;         // Sends answer back to caller
}
// Call it: int sum = add(4, 6); // sum becomes 10

2.2 Function Overloading

Giving multiple functions the exact same name as long as their parameter types or counts differ. C++ automatically picks the right one!

int multiply(int a, int b) { return a * b; }
double multiply(double a, double b) { return a * b; }

2.3 Parameter Passing (Value vs. Reference)

  • Pass by Value void f(int x): Sends a photocopy. Changing x inside the function does NOT touch the original variable.
  • Pass by Reference void f(int &x): Sends the real original variable. Changing x modifies the original!
void addBonus(int &points) { points += 50; } // Modifies original!

2.4 Default Arguments

Fallback values used if the caller skips passing that argument (must be placed on the rightmost parameters):

void greet(string name, string msg = "Welcome!") {
    cout << msg << " " << name;
}
greet("Alex"); // Prints: Welcome! Alex

2.5 Inline Functions

Adding inline suggests to the compiler: "Don't jump to this tiny function—paste its code directly where it's called to save CPU jump time."

inline int square(int x) { return x * x; }

2.6 Recursion

A function that calls itself to solve smaller pieces of the same problem, stopping at a Base Case:

int factorial(int n) {
    if (n <= 1) return 1;          // Base Case (stops infinite loop!)
    return n * factorial(n - 1);   // Recursive step
}

2.7 Lambda Expression

An anonymous, throwaway mini-function written right inside your code using [capture](params){ body }:

auto addTwo = [](int a, int b) { return a + b; };
cout << addTwo(3, 4); // Outputs 7

3. Arrays and Strings (Organized Data Rows)

3.1 Arrays

A fixed-size row of variables of the same type sitting side-by-side in RAM. Counting starts at index 0!

int nums[4] = {10, 20, 30, 40};
cout << nums[0]; // 10 (first item)
nums[2] = 99;    // Changes 30 to 99

3.2 Multidimensional Arrays

An array of arrays—think of a spreadsheet grid with [rows][columns]:

int grid[2][3] = {
    {1, 2, 3},   // Row 0
    {4, 5, 6}    // Row 1
};
cout << grid[1][2]; // Row 1, Col 2 -> 6

3.3 C-Style Strings vs. 3.4 String Class

  • C-Style String (Old way): A raw char array ending with a secret null-terminator '': char word[] = "Hi"; (actually stores {'H', 'i', ''}).
  • std::string Class (Modern way): Dynamic, safe text object from <string> that grows automatically and lets you join words with +.

3.5 Common String Functions

#include <string>
string s = "Hello";
s += " C++";             // Append -> "Hello C++"
s.length();              // Number of chars -> 9
s.substr(0, 5);          // Slice from index 0, length 5 -> "Hello"
s.find("C++");           // Returns starting index -> 6
s.replace(6, 3, "World");// Replaces "C++" with "World"

4. Pointers and References (GPS Coordinates of RAM)

The Atom Truth: Every variable lives at a numbered house address in your computer's RAM (like 0x7ffdf4). Pointers and References let you work directly with those memory addresses!

4.1 Pointers (* and &)

A Pointer is a variable whose value is the RAM address of another variable.

  • &var (Address-of operator): Asks "What is var's house address?"
  • *ptr (Dereference operator): Says "Go to the address stored in ptr and grab the value inside!"
int hp = 100;
int* ptr = &hp;   // ptr stores hp's RAM address
*ptr = 50;        // Walks to that address and changes hp to 50!
cout << hp;       // Outputs 50

4.2 References (&)

A Reference is simply an alias (nickname) for an existing variable. Once attached, both names point to the exact same box in RAM.

int score = 10;
int& alias = score; // alias IS score
alias = 99;         // score is now 99!

4.3 References vs. Pointers

Feature Pointer (int* p) Reference (int& r)
Can be empty (nullptr)? Yes (can point to nothing) No (must attach to a variable immediately)
Can switch targets later? Yes (p = &other;) No (locked to original variable forever)
Syntax to read/edit value Needs *p Clean—use just like a normal variable (r)

5. User-Defined Data Types (Custom Blueprints)

5.1 Structures (struct)

Bundles different data types together under one roof (members are public by default):

struct Player {
    string name;
    int level;
};
Player p1 = {"Neo", 99};
cout << p1.name;

5.2 Unions (union)

Like a struct, EXCEPT all members share the exact same memory space (sized to the largest member). Writing to one overwrites the others—great for saving RAM!

union Data {
    int i;
    float f;
};
Data d;
d.i = 10; // Uses the shared bytes as an int

5.3 Enumeration (enum & enum class)

Replaces confusing magic numbers with readable named constants:

enum class State { Idle, Running, Dead };
State hero = State::Running;

5.4 typedef and using

Creates clean nicknames for long, ugly data types (modern C++ prefers using):

typedef unsigned long long ull;       // Classic C/C++ style
using Byte = unsigned char;           // Modern C++ style (cleaner!)

6. Dynamic Memory Management (Stack vs. Heap)

6.1 Dynamic Memory Allocation

  • Stack Memory: Automatic, fast, small. Variables here vanish automatically when their { } block ends.
  • Heap Memory: Giant pool of RAM you request manually while the program is running—stays alive until YOU destroy it!

6.2 new and delete

  • new reserves Heap memory and returns a pointer to it.
  • delete hands that Heap memory back to the OS. (Use delete[] for arrays!)
int* p = new int(42);      // Allocates 1 int on the Heap
delete p;                  // Frees it!
p = nullptr;               // Good habit: prevents dangling pointers

int* arr = new int[5];     // Allocates array of 5 ints on Heap
delete[] arr;              // MUST use [] to free arrays!

6.3 Memory Leak

What is a Memory Leak? Calling new without ever calling delete (or losing the pointer before freeing it). Your program hoards RAM until the system slows down or crashes!

7. Object-Oriented Programming (OOP)

7.1 OOP & 7.2 Classes and Objects

OOP organizes code around real-world "things" combining data + actions. A Class is the blueprint; an Object is the real house built from that blueprint.

class Car {
public:
    string brand;
    void honk() { cout << brand << " says Beep!
"; }
};
Car myCar;           // Object created from Car class
myCar.brand = "BMW";
myCar.honk();

7.3 Constructors

A special function with the exact same name as the class that runs automatically the instant an object is born (a Destructor ~Car() runs when it dies):

class Box {
public:
    int size;
    Box(int s) : size(s) {} // Constructor initializes size immediately!
};

7.4 Encapsulation

Locking sensitive data inside private: so outsiders can't corrupt it, exposing only safe public: methods (getters/setters):

class BankAccount {
private:
    double balance = 0; // Hidden from direct tampering!
public:
    void deposit(double amt) { if (amt > 0) balance += amt; }
    double getBalance() { return balance; }
};

7.5 Inheritance

A child class automatically inherits properties and methods from a parent class (reusing code):

class Animal { public: void eat() { cout << "Eating..."; } };
class Dog : public Animal { public: void bark() { cout << "Woof!"; } };
// Dog can now both eat() and bark()!

7.6 Polymorphism ("Many Forms")

Calling the same method name on different child objects produces different behaviors using virtual and override:

class Shape { public: virtual void draw() { cout << "Shape"; } };
class Circle : public Shape { public: void draw() override { cout << "Circle"; } };
Shape* s = new Circle();
s->draw(); // Calls Circle's draw() at runtime!

7.7 Abstraction

Hiding messy internal gears behind a simple interface using Pure Virtual Functions (= 0). Any child class MUST implement that function:

class Engine {
public:
    virtual void start() = 0; // Pure virtual = Abstract contract!
};

8. Standard Template Library (STL)

8.1 Templates

Write ONE function or class that works with any data type (T acts as a placeholder type):

template <typename T>
T getMax(T a, T b) { return (a > b) ? a : b; }
// Works for getMax(3, 7) AND getMax(2.5, 9.1)!

8.2 STL Overview (Containers + Iterators + Algorithms)

C++'s built-in superpower toolbox so you never have to code data structures from scratch:

  • 8.3 Algorithms (<algorithm>): Ready-made functions like sort(v.begin(), v.end()), reverse(), find(), and binary_search().
  • 8.4 Containers: Smart data storage boxes (listed below).
  • 8.5 Iterators: Pointer-like objects (v.begin(), v.end()) that step through containers so algorithms can work on any container.

8.6–8.10 Essential STL Containers

Container Header How It Works (In 1 Sentence) Key Commands
8.6 Vector <vector> Dynamic array that resizes itself automatically. v.push_back(x), v.pop_back(), v[i], v.size()
8.7 Stack <stack> LIFO (Last-In, First-Out) — like a stack of plates. s.push(x), s.pop(), s.top()
8.8 Queue <queue> FIFO (First-In, First-Out) — like a movie ticket line. q.push(x), q.pop(), q.front()
8.9 Map <map> Sorted Key → Value dictionary (unique keys). m["apple"] = 5;, m.count("apple")

#include <vector>
#include <algorithm>
vector<int> nums = {40, 10, 30};
nums.push_back(20);
sort(nums.begin(), nums.end()); // Now {10, 20, 30, 40}!

9. Exception Handling (Crash Protection)

9.1 Exception Handling (try, throw, catch)

Instead of letting a runtime error (like dividing by zero) crash your app, you throw an alarm and catch it safely:

try {
    int divisor = 0;
    if (divisor == 0) throw "Cannot divide by zero!";
    cout << 10 / divisor;
} catch (const char* err) {
    cout << "Caught error: " << err;
}

9.2 Exception Handling using Classes & 9.4 User-Defined Exceptions

Pros throw custom classes inheriting from std::exception so errors carry rich details:

#include <exception>
class LowBatteryError : public std::exception {
public:
    const char* what() const noexcept override {
        return "Battery below 5%!";
    }
};
// throw LowBatteryError(); -> catch (const std::exception& e) { cout << e.what(); }

9.3 Stack Unwinding

Stack Unwinding: When an exception is thrown, C++ walks backward up the function call chain looking for a matching catch block—and automatically runs destructors to clean up every local stack variable along the way!

10. File Handling (Saving Data to Disk)

10.1 Files and Streams (<fstream>)

RAM wipes clean when your program closes. File streams save and load permanent files on your hard drive:

  • ofstream (Output File Stream): Writes data to a file.
  • ifstream (Input File Stream): Reads data from a file.
  • fstream: Does both reading and writing.
#include <fstream>
// Write to file
ofstream out("notes.txt");
out << "Saved forever!
";
out.close();

// Read from file
ifstream in("notes.txt");
string line;
getline(in, line); // Reads whole line into 'line'
in.close();

10.2 I/O Redirection

Redirecting standard cin/cout to read from or write to files instead of the keyboard/screen—super popular in competitive programming:

freopen("input.txt", "r", stdin);   // cin now reads from input.txt!
freopen("output.txt", "w", stdout); // cout now writes to output.txt!

11. Multithreading (Doing Multiple Tasks at Once)

11.1 Introduction & 11.2 Creating Threads (<thread>)

A Thread is an independent worker inside your program. Multiple threads let different CPU cores run functions simultaneously:

#include <thread>
void work() { cout << "Worker thread running!
"; }
std::thread t1(work); // Starts work() immediately in parallel!

11.3 std::thread::join() vs. 11.4 detach()

  • t1.join(): Main thread pauses and waits until t1 finishes its job. (Forgetting join() or detach() crashes the program!)
  • t1.detach(): Cuts the cord—t1 runs independently in the background like a daemon.

11.5 Mutex, 11.6 Lock Guard, 11.7 Race Conditions & 11.8 Synchronization

  • 11.7 Race Condition: Bug when two threads edit the same variable at the exact same nanosecond, corrupting the result.
  • 11.5 Mutex (std::mutex): A bathroom key—only ONE thread can lock it at a time; others wait outside.
  • 11.6 Lock Guard (std::lock_guard): Smart wrapper that locks a mutex on creation and automatically unlocks it when leaving scope (even if an exception occurs!).
  • 11.8 Thread Synchronization: Coordinating thread order safely using mutexes and std::condition_variable.
#include <mutex>
std::mutex mtx;
int counter = 0;

void safeIncrement() {
    std::lock_guard<std::mutex> lock(mtx); // Locks here, auto-unlocks at '}'
    counter++;
}

12. Advanced Concepts (Pro-Level C++)

12.1 Preprocessor Directives (#)

Text find-and-replace commands that run before compilation even starts:

#include <iostream>   // Pastes file contents here
#define MAX 100       // Replaces every 'MAX' with 100
#ifndef HEADER_H      // Include guard: prevents double-pasting headers
#define HEADER_H
#endif

12.2 Namespaces

Named folders for your code so two libraries with a function named print() don't collide:

namespace Physics { void run() { cout << "Gravity!"; } }
namespace Audio   { void run() { cout << "Sound!"; } }
Physics::run(); // Calls Physics version cleanly!

12.3 Smart Pointers (<memory>)

Pointers that delete themselves automatically—zero memory leaks!

  • std::unique_ptr<T>: Sole owner (cannot be copied, only moved with std::move()).
  • std::shared_ptr<T>: Reference-counted shared owner—deletes memory only when the last owner dies.
#include <memory>
auto ptr = std::make_unique<int>(99); // Auto-freed when ptr goes out of scope!

12.4 Callbacks

Passing a function into another function so it can be called later when an event finishes (using function pointers or std::function):

#include <functional>
void onDownloadComplete(std::function<void(int)> callback) {
    callback(200); // Triggers the user's function!
}

12.5 Signal Handling (<csignal>)

Intercepting emergency interrupts sent by the Operating System (like pressing Ctrl+C / SIGINT) so your program can save work before exiting:

#include <csignal>
void handleCtrlC(int sig) {
    cout << "
Ctrl+C caught! Cleaning up safely...
";
    exit(sig);
}
// Inside main(): signal(SIGINT, handleCtrlC);

13. Compile & Run Your First File Right Now!

Save a file named hello.cpp, open your terminal, and run:

g++ hello.cpp -o hello && ./hello

Every single concept on this page—from a 1-byte char atom up to multi-core threads and smart pointers—is now in your toolkit. Keep it simple, compile fast, and build cool things!
