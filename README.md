# Learn Almost all, with HTML...? :D

> **No frameworks. No build tools. No `node_modules` black holes. Just double-click an `.html` file and learn.**

Welcome to a collection of dead-simple, self-contained, beginner-friendly tech guides built entirely inside single `.html` files! 

Whether you are 5 years old, brand new to coding, or just tired of overly complicated tutorials, every lesson in this repository teaches you a core technology **inside the very medium of the web itself**—even using HTML to teach HTML! This project is an intiative to make people aware of programming and it's fundamentals in this AI era, where people often get confuse between even on the thought of ```programming```. In this simple project, you might see various tutorials of languages, concepts, visuals and much of related to programming. We chose HTML, as it is one of the widest medium to reach - it's a website, and is sufficient to run on any potato devices also.

---

## 💡 But why learn through `.html` Files?
1. **0 Setup Required:** You don't need to install compilers, servers, or packages. Download a file, double-click it, and it opens straight in your browser.
2. **Learn by Doing :** Every file is both a **readable lesson** on your screen *and* a **live code example** under the hood. Right-click any page $\rightarrow$ **View Page Source** (or open it in Notepad / VS Code) to see how the exact page you are reading was built!
3. **Bloat-Free:** No jargon walls. Concepts are broken down with everyday analogies (like building a house with bricks, paint, and electricity) while still covering the real details that matter.
4. **Progressive Building :** Each lesson builds naturally on the previous one—starting with pure HTML, then layering CSS right on top of the `id`s and `class`es you just learned.

---

## 📚 What's Inside This Repo?
Inside this repository, you will find `.html` files that can be opened on virtually any device with a web browser. They can also be edited, allowing you to customize the content, experiment with examples, or add your own notes.

These files are **not intended to be an exhaustive or highly advanced resource**. Instead, they cover concepts ranging from the fundamentals to slightly more advanced topics, providing a starting point for understanding the language and its core features.

The goal is to make learning straightforward by explaining concepts, showing how the code is structured, and providing practical examples without overwhelming you with unnecessary complexity.

If you want to explore beyond what is covered here, you are absolutely encouraged to do so. Refer to the language's official documentation, trusted learning resources, and other technical sources to deepen your understanding and explore more advanced concepts.

**Think of these files as a starting point, not a limitation.** Learn the basics here, experiment with the code, ask questions, and continue exploring beyond the repository. There is always more to learn.

## 🚀 How to Use This Repository

1. **Clone or Download** this repository to your computer:
   ```bash
   git clone https://github.com/codersilicon/learnbyhtml.git
   ```
2. **Open any `.html` file** in Chrome, Firefox, Edge, or Safari by double-clicking it.
3. **Open the same file in a code editor** (like VS Code, Sublime Text, or even Notepad).
4. **Break things on purpose!** Code something, Edit variables, Change a color, edit a tag, save it then delete it. Do whatever you want. No one to blame you for mistakes.

## 🤝 Contributing

Have an idea for a new single-file `.html` guide (JavaScript, Terminal basics, HTTP, Git, SQL, etc.)? Contributions are super welcome!

Just keep these **Golden Rules** in mind when adding a lesson:
* **Keep it self-contained:** Everything needed for the lesson should live cleanly inside a single `.html` file.
* **Keep it simple as hell:** Explain *what* it is, *why* it exists, and *how* it works using clear, everyday analogies.
* **Keep it breif as hell:** The statement might sound contradicting with above one, but you need to manage this both. Both *simple & breif*.
* **Show, don't just tell:** Whenever possible, demonstrate the concept live right on the page!
* **Keep it human:** AI tools are allowed, but the result must still be simple as hell and sound like a person teaching a friend — see the [AI tools policy](CONTRIBUTING.md#using-ai-tools).

New here? Read the full [Contributing Guide](CONTRIBUTING.md) for a beginner-friendly, step-by-step walkthrough of forking, branching, committing, and opening your first pull request. No experience required. 🙌
