# Learn Almost Everything in Tech, with HTML... Even HTML? :D

> **No frameworks. No build tools. No `node_modules` black holes. Just double-click an `.html` file and learn.**

Welcome to a collection of dead-simple, self-contained, beginner-friendly tech guides built entirely inside single `.html` files! 

Whether you are 5 years old, brand new to coding, or just tired of overly complicated tutorials, every lesson in this repository teaches you a core technology **inside the very medium of the web itself**—even using HTML to teach HTML!

---

## 💡 Why Learn Through `.html` Files?

1. **Zero Setup Required:** You don't need to install compilers, servers, or packages. Download a file, double-click it, and it opens straight in your browser.
2. **Learn by Doing & Inspecting:** Every file is both a **readable lesson** on your screen *and* a **live code example** under the hood. Right-click any page $\rightarrow$ **View Page Source** (or open it in Notepad / VS Code) to see how the exact page you are reading was built!
3. **Bloat-Free & Explained Like You're 5:** No jargon walls. Concepts are broken down with everyday analogies (like building a house with bricks, paint, and electricity) while still covering the real details that matter.
4. **Progressive Building Blocks:** Each lesson builds naturally on the previous one—starting with pure HTML, then layering CSS right on top of the `id`s and `class`es you just learned.

## 📚 What's Inside This Repo?

| File | Topic | What You'll Learn |
| :--- | :--- | :--- |
| `learn-html.html` | **HTML (Pure Structure)** | What tags are (the Sandwich Rule), the 4 skeleton tags, headings, lists, links, images, semantic boxes, forms, HTML entities (`&lt;`, `&gt;`), and `id` vs. `class`. |
| `learn-css.html` | **CSS (Style & Layout)** | What CSS is, Internal (`<style>`) vs. External vs. Inline CSS, targeting HTML `id`s (`#`) and `class`es (`.`), specificity, the Box Model, Flexbox, and `:hover` effects. |
| *(Coming Soon)* | **JavaScript & Beyond** | Bringing the page to life, DOM manipulation, APIs, Git, and more—all inside single `.html` files! |

## 🚀 How to Use This Repository

1. **Clone or Download** this repository to your computer:
   ```bash
   git clone https://github.com/codersilicon/learnbyhtml.git
   ```
2. **Open any `.html` file** in Chrome, Firefox, Edge, or Safari by double-clicking it.
3. **Open the same file in a code editor** (like VS Code, Sublime Text, or even Notepad).
4. **Break things on purpose!** Change a color, edit a tag, save the file, and hit **Refresh (`F5` / `Cmd+R`)** in your browser to see your changes live.

## 🤝 Contributing

Have an idea for a new single-file `.html` guide (JavaScript, Terminal basics, HTTP, Git, SQL, etc.)? Contributions are super welcome!

Just keep these **Golden Rules** in mind when adding a lesson:
* **Keep it self-contained:** Everything needed for the lesson should live cleanly inside a single `.html` file.
* **Keep it simple as hell:** Explain *what* it is, *why* it exists, and *how* it works using clear, everyday analogies.
* **Show, don't just tell:** Whenever possible, demonstrate the concept live right on the page!
