HTML: SKELETON of Websites

HTML stands for HyperText Markup Language. Don't let the big words scare you! It is not a programming language that thinks, solves math, or makes decisions. It is simply a labeling language.

When you open a website, the browser reads your HTML file from top to bottom and asks: "What is this piece? Is it a big title? A story paragraph? A picture? A clickable button?" HTML gives each piece its label.

Think of building a house:

  • HTML is the bricks, walls, and doors (the structure).
  • CSS is the paint, curtains, and carpet (how pretty it looks).
  • JavaScript is the electricity and doorbell (what happens when you press things).

This guide is 100% pure HTML—just the bricks!

1. How an HTML Tag Works (The Sandwich Rule)

HTML wraps words inside tags. Tags use angle brackets—little alligator mouths: < and >.

Almost every tag works like two slices of bread holding fillings in the middle:

<tagname>  Your words or other tags go here  </tagname>
  • Opening tag: <p> tells the browser, "Hey, start a paragraph right here."
  • Content: The text or items sitting inside.
  • Closing tag: </p> has a forward slash (/) before the name. It tells the browser, "Okay, stop the paragraph here."
  • Empty (Void) tags: A few special tags don't hold any words inside them, so they don't need a closing slice of bread! Examples: <br> (line break), <hr> (divider line), and <img> (picture).
  • Nesting (Boxes inside boxes): You can put tags inside other tags—like putting a small toy box inside a bigger box. Just remember to close the inner tag before closing the outer tag!

2. The 4 Skeleton Tags of Every Web Page

No matter how huge or tiny a website is, every single HTML file is built on these exact 4 tags in this exact order:

  1. <!DOCTYPE html> — Written at line 1. It is a wake-up note for the browser that says: "Read this file using modern HTML5 rules."
  2. <html> ... </html> — The giant outer wrapper. Everything on your page lives inside this single box.
  3. <head> ... </head> — The invisible brain of the page. Things inside <head> do not appear on the main screen. Instead, it holds behind-the-scenes settings like <meta charset="UTF-8"> (so emojis and symbols display properly) and <title> ... </title> (the name shown on your browser tab).
  4. <body> ... </body> — The visible stage! Every word, picture, link, and button you see on a website lives inside <body>.

3. Titles & Text Tags

Just like a storybook or newspaper has big chapter titles and smaller sub-titles, HTML has 6 heading levels from <h1> (the biggest boss) down to <h6> (the smallest whisper):

<h1> Main Page Title (Use only once per page!) </h1>

<h2> Major Chapter Heading </h2>

<h3> Sub-chapter Heading </h3>

<h4> Small Group Heading </h4>

<h5> Smaller Note Heading </h5>
<h6> Tiniest Heading </h6>

For normal sentences, we use the paragraph tag: <p> ... </p>. Browsers automatically add a little breathing room above and below each paragraph.

Inside a paragraph, you can wrap specific words to give them extra meaning:

  • <strong> makes text bold to show strong importance.
  • <em> makes text italic to show spoken emphasis (like stressing a word when talking).
  • <mark> paints a yellow highlight behind words, just like a highlighter pen.
  • <code> switches to a typewriter font for computer code.
  • <pre> stands for preformatted text—it keeps all your exact spaces and line breaks just as you typed them.
  • <br> forces an immediate jump to the next line,
    right in the middle of a sentence!
  • <hr> draws a horizontal divider line across the page to separate topics.

4. Making Lists

Whenever you want to list items, HTML gives you two list containers. Inside both of them, every single item is wrapped in an <li> tag (which stands for List Item):

1. Unordered List (<ul>) — Bullet Points

Use <ul> when the order of items does not matter (like a grocery list):

  • <li> Apples </li>
  • <li> Bananas </li>
  • <li> Oranges </li>

2. Ordered List (<ol>) — Numbered Steps

Use <ol> when the step-by-step order does matter (like a recipe or instructions). The browser counts and numbers them automatically!

  1. <li> Put on your socks </li>
  2. <li> Put on your shoes </li>
  3. <li> Tie your shoelaces </li>

5. Attributes, Links & Pictures

Sometimes a tag needs extra instructions to do its job. We write these extra instructions inside the opening tag. They are called attributes, and they always follow the pattern name="value".

Links: The <a> (Anchor) Tag

Links are what make the web a "web"! The <a> tag turns text into a clickable doorway. It needs the href (Hypertext Reference) attribute to know the destination address:

<a href="https://example.com">Visit Example Website</a>

You can also link to another spot on the exact same page using # plus an element's id:

Click me! I use href="#top" to jump straight back to the top!

Pictures: The <img> (Image) Tag

The <img> tag places a picture on your page. It is an empty tag (no closing tag) and relies on two crucial attributes:

  • src="..." (Source) — Tells the browser where to find the image file (a web link or folder path).
  • alt="..." (Alternative text) — A short description of the picture. Screen readers read this aloud to blind users, and it shows up if the image breaks.
<img src="puppy.jpg" alt="A happy brown puppy playing in grass">

6. Invisible Boxes (Generic vs. Semantic Containers)

Imagine dumping all your toys, clothes, and books into one giant pile on the floor. Messy, right? In HTML, we group related tags together inside invisible boxes:

Plain Generic Boxes

  • <div> ... </div> (Division) — A plain cardboard box that stretches across the full width of the page. Great for grouping sections together.
  • <span> ... </span> — A tiny clear sandwich bag that sits inline inside a sentence to wrap just a word or two without breaking the line.

Smart Labeled Boxes (Semantic Tags)

Instead of calling every box a plain <div>, modern HTML gives us boxes with meaningful names so humans, screen readers, and Google search bots know what each part of the page does:

  • <header> — The top welcome area of a page or section (logo, main title).
  • <nav> — The navigation bar holding your main menu links.
  • <main> — The star of the show: the main unique content of the page.
  • <section> — A distinct chapter or topic block (just like each numbered section on this page!).
  • <article> — A standalone piece that makes sense on its own, like a blog post, news story, or product card.
  • <aside> — Side notes, fun facts, or a sidebar related to the main story.
  • <footer> — The bottom strip of the page (author info, copyright, back-to-top links).

7. Tables & Interactive Forms

Tables (<table>) — Grids of Information

When you want to show data in neat rows and columns (like a school timetable or scoreboard), build a <table> row by row:

  • <tr> (Table Row) — Creates one horizontal row from left to right.
  • <th> (Table Header) — A bold, centered title cell at the top of a column.
  • <td> (Table Data) — A regular cell holding a piece of information.
Tag Stands For What It Does
<tr> Table Row Starts a new horizontal row
<th> Table Header Creates a bold column heading
<td> Table Data Holds one normal box of data

Forms (<form>) — Talking Back to the Page

Forms are how visitors type answers, tick boxes, and submit choices:

  • <label> — The text title explaining what to type into a box. Its for="..." attribute connects it to the matching input's id.
  • <input> — A blank box where users can type text, passwords, numbers, or check a checkbox (controlled by its type="..." attribute).
  • <select> & <option> — Creates a dropdown menu with clickable choices inside.
  • <button> — A clickable button!




8. IDs vs. Classes (Name Tags vs. Team Jerseys)

Imagine a classroom with 30 kids. Sometimes you want to call one specific kid, and other times you want to call everyone wearing a red jersey. HTML solves this using two special attributes you can put on any tag: id and class.

1. id="unique-name" is like a Fingerprint or Passport Number:

  • Rule: Every id on a web page must be 100% unique. Never give two tags the same id!
  • Why use it? To point to one exact spot—like making a link jump straight to #ids-and-classes, or linking a <label> to its exact <input> box.

2. class="group-name" is like a School Uniform or Team Jersey:

  • Rule: You can give the exact same class to as many tags as you want (5 paragraphs, 10 buttons, anything!).
  • Bonus power: One tag can belong to multiple groups at once! Just separate the class names with a space, like class="info-box highlight".

9. How to Print Secret Symbols (HTML Entities)

Because HTML uses < and > to build tags, typing them normally confuses the browser—it thinks you are starting a real tag! Whenever you want to show those symbols as plain text on the screen, use special codes starting with & and ending with ;:

  • Write &lt; to display < (Less Than)
  • Write &gt; to display > (Greater Than)
  • Write &amp; to display & (Ampersand)

10. Secret Notes (<!-- Comments -->)

Want to leave a reminder in your code for yourself or a teammate that visitors will never see on the screen? Wrap it inside comment arrows:

<!-- The browser completely ignores everything written inside here! -->
